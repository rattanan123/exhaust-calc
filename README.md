# คำนวณท่อไอเสีย (มอเตอร์ไซค์)

แอปออฟไลน์ (Android APK + เว็บแอปสำหรับ iPhone) สำหรับคนรักรถ/ช่าง — คำนวณความยาวและขนาดคอท่อ, ท่อรวม, แปลงหน่วย นิ้ว↔มม., เทียบพื้นที่หน้าตัดท่อเดิมกับท่อใหม่ และบันทึกผลไว้ในเครื่อง

## ลองบนคอมก่อน (ไม่ต้องลงอะไรเพิ่ม ใช้ Python ที่มีอยู่)
```
cd D:\exhaustProject
python -m http.server 8765 --bind 127.0.0.1
```
แล้วเปิด http://127.0.0.1:8765/www/index.html (กด F12 → โหมดมือถือ เพื่อดูหน้าจอแบบโทรศัพท์)
ทดสอบสูตร: http://127.0.0.1:8765/tests/tests.html ต้องขึ้น "ผ่าน 29/29"

## สร้างไฟล์ APK (ฟรี ผ่าน GitHub — ไม่ต้องลง Android Studio)
1. สร้าง repo ใหม่บน GitHub (เช่น `exhaust-calc`) — ตั้งเป็น Private ก็ได้
2. ในโฟลเดอร์นี้:
   ```
   git init
   git add .
   git commit -m "เริ่มโปรเจกต์"
   git branch -M main
   git remote add origin https://github.com/<ชื่อคุณ>/exhaust-calc.git
   git push -u origin main
   ```
3. ไปที่แท็บ **Actions** ใน repo → รอ "Build APK" เป็นสีเขียว (~5–8 นาที)
4. กดเข้ารอบนั้น → เลื่อนลงที่ **Artifacts** → ดาวน์โหลด `exhaust-calc-debug-apk` (เป็น .zip ข้างในมี `app-debug.apk`)
5. ส่งไฟล์ .apk เข้ามือถือ → เปิดติดตั้ง (ต้องอนุญาต "ติดตั้งแอปจากแหล่งที่ไม่รู้จัก")

ทุกครั้งที่แก้ไฟล์ใน `www/` แล้ว push ขึ้น main จะได้ APK ใหม่อัตโนมัติ (หรือกด **Run workflow** เองในแท็บ Actions)

## iPhone / iPad (เว็บแอป — ฟรี ไม่ต้องใช้ Mac)
ลิงก์: **https://rattanan123.github.io/exhaust-calc/** (อัปเดตอัตโนมัติทุกครั้งที่ push ไฟล์ใน `www/` — workflow "Deploy web app")
1. เปิดลิงก์ด้วย **Safari**
2. กดปุ่ม **แชร์** (สี่เหลี่ยมมีลูกศรขึ้น) → **เพิ่มไปยังหน้าจอโฮม** → **เพิ่ม**
3. จะได้ไอคอน "ท่อไอเสีย" บนหน้าจอ เปิดแบบเต็มจอเหมือนแอป และใช้ได้ตอนไม่มีเน็ต (หลังเปิดครั้งแรกตอนมีเน็ต)
- Android ก็ใช้ลิงก์นี้ได้: Chrome → เมนู ⋮ → **ติดตั้งแอป**
- แก้โค้ดแล้ว ผู้ใช้จะได้เวอร์ชันใหม่ตอนเปิดแอปครั้งถัดไปที่มีเน็ต (`www/sw.js` — ถ้าเพิ่ม/ลบไฟล์ใน `www/` ให้แก้รายการ `ASSETS` และเปลี่ยน `VERSION`)
- ประวัติที่บันทึกในเว็บแอปกับในแอป APK แยกกัน (เก็บคนละที่ในเครื่อง)
